## Analysis

### 1. Position Sizing (5% → 2%)
- **효과**: Max DD 75.8% → 42.3% (거의 절반)
- **비용**: 수익 $7.1K → $3.7K
- **결론**: 리스크 관리에 가장 효과적. 수익은 줄지만 파산 위험 크게 감소.

### 2. NO만 거래 (YES 제외)
- **효과**: 거래 877 → 459 (절반), 승률 49.7% → 50.5%
- **이유**: "BTC above $X" 마켓에서 NO가 더 수익적 — 가격이 threshold 아래로 떨어지는 경우가 약간 더 예측 가능
- **결론**: 거래 절반, 관리 편함, 수익률 비슷. 적용 추천.

### 3. 가까운 Threshold만 (<0.5%)
- **효과**: 승률 49.7% → 52.6% (최고)
- **이유**: 현재가에서 0.5% 이내 threshold가 가장 예측 가능 — sigmoid가 정확
- **비용**: 거래 877 → 650
- **결론**: 승률 개선에 효과적. 먼 threshold는 노이즈가 커서 예측력 떨어짐.

### 4. Fee 절감 (7c → 3c, 리밋 오더)
- **효과**: 거래당 수익 +9.7% → +11.7%, 총 수익 $7.1K → $16.4K
- **이유**: 수수료가 수익에서 차지하는 비율이 큼. 리밋 오더는 Kalshi에서 fee 할인
- **결론**: 가장 큰 임팩트. 이미 리밋 오더로 전환 완료 — 효과 자동 반영.

### 5. Edge 8%+ 필터
- **효과**: 거래 0건 — 8% 이상 엣지가 3-8c 미스프라이싱에서 불가능
- **결론**: 사용 불가. 현재 5% 유지가 적절.

### 6. 조합 #7 (추천)
- **NO만 + 리밋 fee + Position 2%**
- **효과**: DD 33%에 +142% 수익 ($1K → $2.4K)
- **장점**: 가장 낮은 drawdown, 충분한 수익, 관리 간편
- **적용**: spread_scanner에 NO-only 모드 추가, position sizing 2%
